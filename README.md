# Sample Project README

This repository was created in order to complete the Server Administration CAT II assignment.

## Project Overview

This project is a simple PHP-based web application that demonstrates basic server administration and web application functionality, including:

- User signup and login
- Dashboard access
- Feedback handling
- Session/logout management
- Basic styling and page layout

## Purpose

The primary goal of this repository is to support the practical work required for the Server Administration CAT II coursework. It serves as a sample project for learning, implementation, and documentation of core web application and server management concepts.

## Files Included

- `index.php` – landing page
- `login.php` – user login page
- `signup.php` – user registration page
- `dashboard.php` – authenticated user dashboard
- `feedback.php` – feedback form/page
- `config.php` – application configuration
- `logout.php` – logout logic
- `style.css` – styling for the application
